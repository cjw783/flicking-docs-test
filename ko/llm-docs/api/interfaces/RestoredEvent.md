# RestoredEvent

> Event that fires AFTER Flicking has returned to [currentPanel](https://cjw783.github.io/flicking-docs-test/docs/api/classes/Flicking#currentpanel).

## Description

Fired after the restoration animation completes and the camera has returned to the current panel.

## Properties

### isTrusted

**Type:** `boolean`

Boolean that indicates whether the event was generated by a user action
