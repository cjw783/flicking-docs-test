# GetStatusParams

> Parameters for [getStatus](https://cjw783.github.io/flicking-docs-test/docs/api/classes/Flicking#getstatus)

## Properties

### includePanelHTML

**Type:** `boolean`

Include panel's `outerHTML`

**Default:** `false`

*This property is optional.*

### index

**Type:** `boolean`

Include current panel index

**Default:** `true`

*This property is optional.*

### position

**Type:** `boolean`

Include camera position. Only works when [moveType](https://cjw783.github.io/flicking-docs-test/docs/api/FlickingOptions#movetype) is `freeScroll`

**Default:** `true`

*This property is optional.*

### visiblePanelsOnly

**Type:** `boolean`

Include only visible panels' HTML. Only available when `includePanelHTML` is `true`

**Default:** `false`

*This property is optional.*
